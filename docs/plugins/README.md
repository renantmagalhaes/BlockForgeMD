# Plugins

BlockForgeMD ships with a small plugin store (**Settings → Plugins**) for connecting external tools, calendars, and AI providers directly into your workspace.

## Plugin configuration is fully per-user

Every user's plugin configuration is completely independent — there is no shared/instance-wide config. Concretely, for Google Calendar: each person creates and pastes in their own Google OAuth Client ID/Secret, sets their own poll interval and workspace sync scope, and connects their own Google account. Nothing one user configures affects any other user on the instance — there's no "whoever sets it up first sets it up for everyone" concern.

This does mean every user who wants a plugin's integration has to do that plugin's setup themselves (e.g. creating their own Google Cloud OAuth Client for Google Calendar) — it isn't a one-time admin task that everyone else then benefits from.

Google Calendar also routes sync **per page**, not just per user: a due-dated page only syncs to the one connected account whose username matches the page's `assignee` field (auto-set to the creator on new pages) — see [google-calendar.md](google-calendar.md#how-sync-works) for details.

## Available

- **[Google Calendar](google-calendar.md)** — 2-way sync between any page's due date and events on your Google Calendar.
- **[Ollama Auto Tags](ollama-tagger.md)** — contextual Markdown tags generated by your own Ollama server.
